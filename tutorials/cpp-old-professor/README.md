# C++ 老教授进阶基础教程

这组教程面向已经会写一点 C++、但希望把“能跑”提升到“可靠、可维护、现代 C++20”的学习者。风格上参考一位严谨的 C++ 老教授：少背语法表，多追问对象生命周期、资源所有权、类型边界和工程可验证性。

## 学习路线

1. [值语义、生命周期与 RAII](01-value-lifetime-raii.md)
2. [类型设计、接口边界与 `const`](02-types-interfaces-const.md)
3. [错误处理、异常安全与资源回滚](03-errors-exception-safety.md)
4. [STL、迭代器与算法思维](04-stl-iterators-algorithms.md)
5. [现代 C++20 工程小练习](05-cpp20-practice-lab.md)

## 使用建议

- 每节先读“老教授板书”，再完成“课堂练习”。
- 所有示例都尽量避免炫技，重点是养成可解释的设计习惯。
- 学习时请持续运行项目已有的 CMake 构建与测试，确保教程代码可以被逐步移入 `src/` 练习。
